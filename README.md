# Defox SEO Suite Lite for Magento 2

SEO module for Magento 2.4.7 – 2.4.9: meta tag templates, JSON-LD structured data, canonical and NOINDEX control, per-store XML sitemaps and friendly filter URLs.

## Features

- **Meta tag templates** (title, description, keywords, robots, Open Graph) for products, categories and CMS pages, with variables such as `{{product.name}}`. Optionally fill only empty meta fields.
- **JSON-LD structured data**: Organization, WebSite, Product (offers, ratings, reviews, return policy, shipping details), Category, CMS page / AboutPage / Article. Attribute mapping for brand, GTIN, MPN, condition and custom properties.
- **Structured Data Preview** in the admin with a built-in validator.
- **Canonical URLs** for products (with or without category path), categories (pagination, filters) and CMS pages.
- **NOINDEX** for filtered listings, invalid filter values and configurable URL patterns.
- **XML sitemap per store view**: products (with images), categories, CMS pages, custom links, hreflang, gzip, sitemap index for large catalogs. Generated by cron or from the admin, with validation and statistics.
- **Friendly filter URLs** in layered navigation, e.g. `/category/color-red/size-m.html` (disabled by default).
- Granular ACL: view, save and delete meta templates; sitemap generation, validation and dashboard; configuration.

## Requirements

- Magento 2.4.7 – 2.4.9, PHP 8.2 – 8.5, `ext-zlib`
- Optional: `Magento_Review` (ratings in JSON-LD), `Magento_Swatches` (friendly URLs for swatch options). They may be disabled, but their packages must stay installed.

## Installation

Back up the database first: the declarative schema removes obsolete tables from earlier versions.

Copy the module to `app/code/Defox/SEOSuite`, or install it with Composer:

```bash
composer config repositories.defox-seosuite vcs https://github.com/MLisiecki/magento2-defox-seosuite-lite
composer require defox/seosuite-lite
```

Then:

```bash
bin/magento module:enable Defox_SEOSuite
bin/magento setup:upgrade
bin/magento setup:di:compile
bin/magento cache:flush
```

Flush the Full Page Cache after every configuration change; meta tags and JSON-LD are cached with the page.

## Configuration

- **Stores > Configuration > Defox > SEO Suite Lite**: general switch, meta tags, canonical, friendly URLs, structured data, XML sitemap.
- **Marketing > SEO Suite Lite**: meta tag templates, sitemap overview / generation / validation / analytics, Structured Data Preview.

Use Google's [Rich Results Test](https://search.google.com/test/rich-results) to check the output. Missing GTIN, brand or delivery time warnings mean the shop data is incomplete; the module does not guess values.

## Upgrading from 1.x

- Sitemap files are now named `<store_code>_sitemap.xml` (or `_sitemap_index.xml`). Old `sitemap*.xml` files are not deleted; update `robots.txt` and Google Search Console.
- Friendly URLs are disabled by default and option keys use store view labels; previously indexed filter URLs may change.
- NOINDEX is applied only when canonical URLs are enabled.
- Existing admin roles need the new **Save Templates** / **Delete Templates** permissions to edit templates.
